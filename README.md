# Smart-Ring-IOT

Personal health tracker: a QRing-family smart ring (Ruofine R09/R10) syncs over BLE
to a home hub (2014 MacBook Air, Linux Mint) that stores, analyzes, and serves a PWA
dashboard. No cloud, no accounts, no subscriptions — data never leaves hardware the
owner controls.

**Status:** framework phase — hardware purchase deferred on funding; hub, parsers,
and dashboard are being built and proven against synthetic data (Phase 0a).

See `PLAN.md` for the full plan, `RESOURCES.md` for external references, and
`HUB_SETUP.md` for the hub machine build-out. `CLAUDE.md` documents the engineering
rules and repo conventions for AI-assisted work in this repo.
